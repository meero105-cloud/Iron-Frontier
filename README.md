# 철의 경계선 (Iron Frontier)

실제 세계 지도(3D 지구본) 위에서 펼치는 세계대전 전략 게임입니다. 구석기·신석기·청동기·철기 시대와 현대 시나리오 중 하나를 골라 시작하고, 턴제 또는 실시간(1초 = 하루)으로 플레이할 수 있습니다.

## 바로 플레이하기

1. `iron-frontier.html` 파일을 내려받습니다.
2. 크롬, 엣지, 사파리 같은 웹 브라우저로 파일을 엽니다(더블클릭).
3. 시나리오, 난이도(쉬움·보통·어려움), 진행 방식(턴제·실시간)을 고르고 시작합니다.

인터넷 연결이 필요합니다. 지도 라이브러리(D3, topojson)를 CDN에서 불러옵니다.

## 주요 기능

- 드래그로 돌리는 3D 지구본, 확대하면 특산품과 건물 표시
- 전쟁 안개와 탐험 단계 (고대 시대는 먼 땅을 모르는 상태로 시작)
- 내정(건물 4종), 국방(무기 3단계, 모병, 식량 유지비), 외교(평화·병합·항복 요구·선전포고·평판), 무역(교역 협정·시장)
- 시대별로 바뀌는 이름 (예: 구석기는 밭·집·신전·가축, 투척·창·우마)
- 전선 애니메이션, NATO식 부대 표식, 공격 화살표·폭발 효과, 전투 보고서, 효과음

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `iron-frontier.html` | 현재 게임 본체 (이 파일만 열면 됩니다) |
| `iron-frontier.backup-before-visual.html` | 전쟁 전략 스타일 비주얼 개편 이전 백업 |
| `template.html` | 예전 원본 템플릿 (`__TOPO__` 자리에 지도 데이터를 넣어 만들던 파일, 지금은 최신이 아님) |

앞으로는 `iron-frontier.html`을 직접 고치면 됩니다.
